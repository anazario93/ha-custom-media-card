# Custom Media Player Card

A customizable Home Assistant Lovelace media player card with a visual configuration editor.

## Planned features

- Select a `media_player` entity
- Album artwork alongside title, artist, and album metadata
- Independently show or hide playback controls, progress, volume, and metadata
- Horizontal, vertical, and compact layouts
- Home Assistant visual editor support
- HACS-compatible frontend resource
